Background

Graph와 AI, 새로운 인텔리전스의 시작

Graph는 관계와 구조를, AI는 언어와 맥락을 다룹니다.
두 기술이 결합된 Graph AI는 관계 구조를 근거로 발견하고 판단하고 행동합니다.

Graph

구조를 보는 힘

무엇이 무엇과 연결되어 있는가, 전체 구조에서 어떤 위치인가, 숨은 패턴과 역할은 무엇인가 — 관계와 구조를 표현·탐색·분석합니다.

“

Question

"A가 퇴사할 경우, 회사의 업무적 소통에 어떤 영향을 미치나?"

↓
Step 1

질문 의도·데이터 현황 파악

AI가 질문의 의도('퇴사 영향도 분석')를 분석하고, 해당 인원을 제외한 데이터를 구성해 퇴사 전·후를 비교할 준비를 합니다.

특정 인원 제외한 퇴사 전·후 비교 데이터 구성
Step 2

분석 설계 · NetMiner 자동 실행

NetMiner를 자동 실행해 퇴사 전·후 네트워크를 각각 시각화하고, 구조적 특성(Network Properties)을 비교 분석합니다. 분석 옵션과 결과는 세션 로그로 자동 저장됩니다.

퇴사 전·후 네트워크 자동 비교·시각화
Step 3

분석 결과 자연어 해석

네트워크 특성 지표의 변화를 HR 관점에서 종합 해석해, 소통 관계에 미치는 리스크와 변화를 요약 리포트로 제공합니다.

범용 AI: 일반적인 개념 설명 위주, 실제 워크플로우 설계는 사용자 몫

Automation

설계된 흐름에 따라 NetMiner 분석과 시각화를 자동으로 실행하고, 정리된 결과를 바로 확인할 수 있습니다.

범용 AI: 분석 도구 제어 불가, 코드 실행·오류 수정은 사용자 직접

Zero-Hallucination

경로·출처 기반의 근거 있는 답변

NetMiner로 분석을 수행하면서 옵션과 결과를 그대로 보존해, 그럴듯한 답변이 아닌 실행 경로·출처에 근거한 답변을 제공합니다.
